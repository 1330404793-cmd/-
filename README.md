# 信息权限管理网站

这是一个动态网站原型，包含普通用户登录、信息浏览、修改密码，以及管理员后台的用户管理和信息发布。前端通过接口调用本地 Node 后端，数据保存在项目目录的 `data.json` 文件中。

## 打开方式

先在当前目录启动服务：

```bash
node server.js
```

也可以双击 `start-server.bat`，或运行：

```bash
npm start
```

然后在浏览器中访问：

```text
http://127.0.0.1:5500/index.html
```

## 演示账号

- 管理员：tang / 1101
- 普通用户：user / user123

浏览器只保存登录令牌；用户、密码、信息内容会保存到后端的 `data.json`。
